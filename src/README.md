# KFO UI System

طبقة المكونات الأولى لإعادة بناء كفو.

## القواعد
- RTL-first
- IBM Plex Sans Arabic للنص العربي
- Inter للأرقام والمؤشرات
- Design tokens موحدة
- الشعار والأصول الأصلية فقط
- لا تستخدم صور المعاينات داخل المنتج

## المكونات
Header, Hero, FeatureCard, MetricCard, DashboardShell, Sidebar, CourseCard, CoursePlayer.
