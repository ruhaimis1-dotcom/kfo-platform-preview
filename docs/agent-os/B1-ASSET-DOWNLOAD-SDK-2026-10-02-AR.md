# متابعة G1 — توقف التنزيل وتصحيح فاحص SDK

تحقق الوكيل من هوية الحسابات في جلسة المعاينة مباشرة: BM نجح 6/6 لفحص الأدوار؛ EM نجح 6/6، بما فيه عدم توسيع صلاحياته. موظف A يحمل CO مؤقتًا في شركة QA-B فقط. نجح تحضير B 5/5 ثم تحضير A من saud@hirely.sa 5/5. كلا الملفين مثبت بالمحتوى والتنزيل عبر الرابط المؤقت؛ لا إعادة رفع فوق ملف قائم.

عند تشغيل العزل من A نجحت الفحوص الأربعة للملف المملوك، ثم توقف فحص منع قراءة B. لم ينفذ توقيع B أو كتابة probe أجنبية. هذه نتيجة غير ناجحة؛ لا تثبت تسربًا ولا تثبت منعًا. بقي الملفان للاختبار اللاحق؛ لا تنظيف قبل فحص الاتجاهين.

راجعنا المكتبة المقفلة: supabase-js 2.58.0 / storage-js 2.12.2. يستخدم تنزيلها `noResolveJson`، لذلك يعاد رفض HTTP على شكل StorageUnknownError يضم Response في originalError، دون statusCode/message اللذين اشترطهما الفاحص. اختبار تكاملي محلي بالمكتبة الفعلية واستجابة HTTP محاكية أعاد نفس توقف الفاحص القديم. الاستجابة الحية التفصيلية غير معروضة في الواجهة الحالية؛ يلزم إعادة الفحص بعد النشر المعتمد قبل تحديد نتيجة العزل الحية.

التصحيح محلي: قراءة نسخة من استجابة التنزيل الفاشل فقط عند كونها Response داخل StorageUnknownError؛ اشتراط HTTP 400/403/404 ورسالة رفض معروفة ورمز جسم مقبول إن وُجد. أخطاء الشبكة و500 وJSON غير صالح ورسالة غير متوقعة لا تمر. توقيع/رفع الملفات يبقيان فحص API المعتاد مع تحقق رمز HTTP أيضًا، ولا تمر كتابة تعيد بيانات. يعرض التقرير رمز HTTP فقط دون جسم الاستجابة أو الأصل أو رؤوس الطلب أو رابط موقع.

التحقق: npm run check نجح (بناء + 44 اختبارًا). اختبارات SDK تستخدم الشبكة المحاكية فقط، وليست جلسات HTTP حية. لا تغيير لسياسات Storage أو قاعدة البيانات أو الأدوار. لا نشر ولا push ولا دمج إنتاج لهذه الجولة حتى اعتماد تحديث معاينة QA. المصدر المنشور مستعاد محليًا من HEAD 51b8332d361c58830fec4c731ff22be9fdb059e6؛ التعديلات القديمة غير المرفوعة لشريحة بيانات الشركات لم تُستعد.

بعد الاعتماد: تحديث المعاينة وإعادة تحميل جلسة سعود؛ تحقق هوية الحساب ثم فحص A دون تحضير جديد. الدخول الموظف للفحص المعاكس وتنظيف B، ثم تنظيف A من سعود. بعد تحقق غياب الملفات، تعطيل B وعضويتها المؤقتة عبر اتصال Supabase الإداري؛ آخر محاولة قراءة إدارية رفضت الصلاحية. G1 ما زالت مفتوحة.
