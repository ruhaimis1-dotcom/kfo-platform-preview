# نبرة كفو وكتابة الواجهات

قرار تحريري للمراجعة — 29 سبتمبر 2026. النبرة المقترحة: **مهنية ودودة بعربية سهلة**. نخاطب المستخدم بصيغة مباشرة مثل «أهلاً بك» و«تابع تقدم فريقك»، ونستخدم مفردات مألوفة في السعودية من دون تحويل الواجهة إلى لهجة محكية أو خطاب رسمي ثقيل. يبقى اسم الدور والإجراء ومجال الصلاحية واضحًا.

## قواعد التنفيذ

- عنوان قصير يصف الفائدة أو الخطوة، يليه سطر يوضح ما سيحدث. فعل واحد واضح لكل زر.
- رسالة الخطأ تذكر ما يستطيع المستخدم فعله الآن؛ لا تعرض تفاصيل تقنية، ولا تجزم بأن البريد موجود أو غير موجود.
- في الدعوات، نفرّق بين إنشاء حساب Auth ودعوة عضوية الشركة. لا نقول «أرسلنا دعوة» إلا إذا أُرسلت رسالة فعلًا.
- لا نصف أرقام المعاينة أو صلاحياتها على أنها بيانات حقيقية. لا نَعِد بمساحة عمل أو انتقال تلقائي قبل ربطهما فعليًا.
- حافظ على المصطلحات: «مسار»، «دورة»، «فريق»، «فرع»، «عضوية»، «مقعد»، «شهادة»، «تسجيل الدخول»، «إعادة تعيين كلمة المرور». تجنب التبديل غير المبرر بين المرادفات.

## أمثلة قبل/بعد

| السياق | أقل وضوحًا | نبرة كفو |
| --- | --- | --- |
| دخول | أدخل بيانات حسابك للمتابعة | أدخل بريدك وكلمة المرور للمتابعة |
| خطأ اعتماد | البريد الإلكتروني أو كلمة المرور غير صحيحة | تعذر تسجيل الدخول بهذه البيانات. تحقق من بريدك وكلمة المرور، أو عيّن كلمة مرور جديدة |
| استعادة | أرسل رابط الاستعادة إلى بريدك | أدخل بريد حسابك في كفو، وسنرسل لك رابط الاستعادة |
| معاينة | مؤشر الجاهزية 92% | مثال توضيحي لمؤشر الجاهزية، إن عُرض رقم تجريبي |

تُراجع صفحات كفو العامة ولوحات الشركة تباعًا قبل اعتماد النصوص النهائية، مع المحافظة على المسارات والتصميم المعتمدين. هذه الوثيقة تضبط الأسلوب ولا تعتبر اعتمادًا للنشر أو لميزات غير مكتملة.
