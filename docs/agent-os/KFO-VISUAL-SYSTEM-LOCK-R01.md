# KFO Visual System Lock R01

Status: LOCKED for implementation review  
Reference: KFO approved visual applications / matching preview  
Scope: Homepage, Auth, Learner Workspace, Company Portal, Admin, Course Catalogue, Course Player.

## Brand core

Use these values as the only decorative brand palette:

- Forest Ink: `#04180F`
- Deep Teal: `#123B32`
- Operational Green: `#205E1E`
- Signal Green: `#419B2A`
- Mist: `#F4F6F8`
- Sage Tint: `#E7EEE9`

Recommended visual balance from the approved reference:
- 55% neutral surfaces
- 25% light surfaces
- 15% deep brand
- 5% signal green

## Product character

KFO is a serious B2B learning operating system:
- calm, dense, decision-first;
- information before decoration;
- restrained shadows;
- restrained gradients;
- consistent hierarchy;
- Signal Green is for emphasis/state/action, not the dominant surface color.

## Logo

- `upload/logo.png` must remain byte-identical to the approved `logo-approved.png`.
- Use `upload/logo-white.png` only on dark surfaces.
- Never stretch, rotate, outline, recolor, or recreate the mark.
- Preserve breathing room around the complete lockup.

## Components

### Radius
- Default product cards/panels: 8–12px.
- Pills/status chips may use full radius.
- Avoid decorative oversized rounding.

### Shadows
- Default product panels: none or extremely subtle.
- Do not use shadows to create hierarchy when border/spacing can do it.

### Buttons
- Primary: Deep Teal.
- Primary hover: Operational Green.
- Secondary: white + brand line + Deep Teal text.
- Signal Green may be used for a singular high-emphasis action, not every button.

### Brand vs semantic colors
Brand surfaces use only the locked palette above.
Semantic warning/error colors are allowed only for true system meaning:
- error/destructive;
- warning/due;
- success when it communicates a real state.
They must never be used as decorative alternatives to the brand palette.

## Application rules

### Homepage
Product-led, no fabricated metrics, no decorative fake analytics, no decorative arrows.

### Auth
Deep Teal story panel, calm neutral form side, no gradients.

### Company/Admin
Dense and operational. No CRM-style decoration. Data/actions should lead the hierarchy.

### Learner/Course
Lighter than Admin but visually the same system.

### Course Player
Must not introduce a separate palette. The previous yellow-green accent is prohibited.

### Certificates
High-trust touchpoint. Must use approved logo, restrained brand palette and verifiable course/learner data only.

## Prohibited drift tokens

Do not reintroduce:
- `#D9FF5A`
- `#17251F`
- `#18211D`
- `#103B2E`
- `#267A43`

Any new decorative green requires an explicit Visual System revision.
